# NEED TO KNOW

説明されない実験に送り込まれ、観察と推理で生存手順を組み立てるサバイバルホラーの企画です。

現在は「歩調」1室の操作縦切りを実装した段階です。朝・召集・実験・聴取・夜・死亡継承・保存までをブラウザで遊べます。名札・給水器・白い扉、人によるプレイテスト、数値の実測は未実施です。

## 動かす

依存パッケージはありません。ES modules を使うため、ローカルHTTPサーバー経由で開きます。

```sh
npm run serve
# http://localhost:4173
```

Node.js がある場合はテストも実行できます。

```sh
npm test
```

## いま実装されているもの

| 範囲 | 内容 |
| --- | --- |
| 歩調 | 24距離単位の通路、箱の回収、120秒の期限、速度3段階、追従音、接近、危険時計3秒、停止0.5秒／低速1秒の解除 |
| 指示 | 回収後の「走ってください」、従う／遅らせる／逆らう／質問する、赤線から青線の8距離単位の走行判定 |
| 観察と公正さ | 前兆と字幕と音の同時提示、ポーズ・ノート・フォーカス喪失中の停止、前兆への反応では疑念を加算しない |
| ノート | 観測カード、伝聞カード、自由記述の仮説、夜の封筒複写（3件・1枠） |
| 聴取 | 5種類の返答、信用C・疑念Sの更新、同一実験の減点上限、疑念3での記憶処理 |
| 1日ループ | 朝2枠・夜2枠、配布文書、同房者、安全な再評価業務、6日目の監督用名札 |
| 死亡と継承 | 死亡報告、日付+1、新しい被験者、C/S/Eとノートの初期化、封筒と施設ルールの保持 |
| 終了 | 7日目の処分／有用認定、条件を満たした場合の脱走未遂、事後報告履歴 |
| 保存 | localStorage への自動保存、途中再開、破損時に元データを上書きしない退避 |

**未実装**: 名札、給水器、白い扉、手続き生成、幻覚、体力、NPCの自律生活、脱走の成功、本編の30日構造。

**未検証**: 人が遊びやすいか、目標時間、難易度、音の聞こえ方、予備知識による差。距離・秒数・閾値はすべて試作用の初期値です。

## 操作

| 入力 | 動作 |
| --- | --- |
| W A S D / 矢印 | 移動 |
| Shift（保持） | 走行 |
| Z（保持）/ C（切替） | 低速歩行 |
| E / クリック | 調べる・箱を回収する |
| マウス | 向き（向きだけでは速度は変わらない） |
| Tab | ノート（実験時計を止める） |
| Esc | ポーズ |

## 実装の構成

```text
index.html                 画面の骨格
assets/styles.css          外観
src/core/constants.js      速度・距離・時間の初期値
src/core/footstep.js       歩調の状態機械（描画非依存）
src/core/progress.js       信用・疑念・聴取・記憶処理・終了判定
src/core/model.js          施設サイクル・被験者・ノート・封筒・日付遷移
src/core/storage.js        保存の読み書きと破損時の退避
src/app/trial.js           入力・固定時間ステップ・音のスケジューリング
src/app/render.js          Canvas 2D の描画
src/app/screens.js         DOM画面（朝・聴取・夜・死亡・ノート）
src/app/main.js            画面遷移と保存の結合
tests/                     中核ロジックの自動テスト
docs/IMPLEMENTATION.md     受入条件との対応、判断と未検証項目
```

判定は `src/core/` に閉じ、DOM・Canvas・音に依存させていません。`node --test` で判定だけを検証できます。
