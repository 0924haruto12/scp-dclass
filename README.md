# NEED TO KNOW

説明されない実験に送り込まれ、観察と推理で生存手順を組み立てるサバイバルホラーの企画です。

現在は設計段階です。ゲーム本体は未実装で、プレイテストも未実施です。レビューとMVP仕様は採否未確定の提案として管理します。

## 最初の検証

「歩調」1室で、前兆の観察、回避、指示との衝突、聴取、事後報告を一巡させます。仕様中の距離・秒数・閾値・所要時間は試作用の仮置きで、実測結果ではありません。

SCP世界か独自世界か、エンジン、対象OS、正式タイトル、配布方法、収益化は未決です。
