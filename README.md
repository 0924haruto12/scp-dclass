## 歩調縦切りの試作

ブラウザで動く試作です。判定は `src/core/` にエンジン非依存のTypeScriptで実装し、画面・音は `src/game/` に分けています。範囲、仕様の解釈、受入条件の状況は[実装メモ](docs/implementation/NEED_TO_KNOW_歩調縦切り_実装メモ.md)にまとめています。

```sh
npm install
npm run dev        # http://localhost:5173 を開く。?dev を付けるとF3で開発用ログ
npm test           # 受入条件の自動テスト
npm run typecheck
npm run build
```

操作: WASDで移動、矢印キーかマウスで視線、Shiftで走る、Cで低速（Vで切替）、Eで調べる、1〜4でインターホンへ返答、Tabでノート、Escで一時停止。

## 最初の検証

「歩調」1室で、前兆の観察、回避、指示との衝突、聴取、事後報告を一巡させます。仕様中の距離・秒数・閾値・所要時間は試作用の仮置きで、実測結果ではありません。

SCP世界か独自世界か、エンジン、対象OS、正式タイトル、配布方法、収益化は未決です。ブラウザ版はエンジン選定前の検証用で、採用を決めたものではありません。
