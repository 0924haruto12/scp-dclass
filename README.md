# NEED TO KNOW

説明されない実験に送り込まれ、観察と推理で生存手順を組み立てるサバイバルホラーの企画です。

「歩調」1室の操作縦切りを、ローカルWeb試作として実装しました。入室、回収、前兆への対処、聴取、ノート、事後報告、死亡後の被験者交代まで遊べます。7日MVP全体と人によるプレイテストは未実施です。

## 試作を動かす

Node.js 22以降で、次を実行します。依存パッケージのインストールは不要です。

```sh
npm run dev
```

[http://127.0.0.1:4174](http://127.0.0.1:4174) をデスクトップブラウザで開いてください。他モデルの試作とポートが競合する場合は `PORT=4175 npm run dev` で変更できます。

| 操作 | 入力 |
| --- | --- |
| 移動 | WASD / 矢印キー |
| 走行 | Shiftを保持 |
| 低速歩行 | Altを保持。設定で切替式にするとC |
| 向き | マウス |
| 調べる・箱を持つ・退出 | E |
| インターホンへの返答 | 1〜4 / 画面のボタン |
| ノート / ポーズ | N / Esc |

ノート、設定、フォーカス喪失中は実験が止まります。保存はブラウザのlocalStorageに行い、再開時は一時停止した状態に戻ります。保存が読めない場合は原本を保護し、書き出しと別枠保存の後に新規開始できます。「記録を書き出す」はバックアップ用で、この試作にファイル取込機能はありません。

```sh
npm test
npm run check
```

ブラウザ操作テストは任意の開発用Playwrightが必要です。実行方法、確認範囲、未実装項目は[実装記録](docs/implementation/codex-vertical-slice.md)を参照してください。実行時の外部パッケージ・画像・音声素材・API通信は使いません。

## 最初の検証

「歩調」1室で、前兆の観察、回避、指示との衝突、聴取、事後報告を一巡させます。仕様中の距離・秒数・閾値・所要時間は試作用の仮置きで、遊びやすさを実測した結果ではありません。

本試作はJavaScript＋Canvas 2Dによる見下ろし表示です。SCP世界か独自世界か、製品版のエンジン・対象OS、正式タイトル、配布方法、収益化は未決です。レビューとMVP仕様案の残りを一括採用した扱いにはしません。
