# NEED TO KNOW

説明されない実験に送り込まれ、観察と推理で生存手順を組み立てるサバイバルホラーの企画および実装です。

現在の実装は、4モデルが並行して作った試作を1本に整理した**統合プロトタイプ**を、**1ラン30日**へ拡張したものです。土台はAntigravity版（7日間MVP・異常4種）で、他3本からは実験中保存、保存障害の保護、ブラウザ検証を移植し、30日スケジュール・再設置給水器・30日目終了判定・旧保存の移行を追加しました。人による30日間の通しプレイテストは未実施で、仕様案の採択や受入完了を意味しません。経緯は[統合メモ](docs/implementation/統合メモ.md)、[30日化メモ](docs/implementation/30日化メモ.md)、[ブランチ比較](docs/implementation/ブランチ比較.md)にあります。

## クイックスタート

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（ブラウザでプレイ）
npm run dev

# 本番ビルド（型チェック＋Viteビルド）
npm run build

# 受入条件（AC01〜AC15）と30日ランの自動テスト
npm test

# 任意: Playwrightがある環境でのブラウザ検証
npm run test:browser

# 任意: Playwrightがある環境で30日間をUI操作で通す検証
npm run test:30day
```

`test:browser` / `test:30day` はPlaywrightを依存に含めていない。既存の `playwright` / `playwright-core` を使う場合は `PLAYWRIGHT_MODULE` を、Chromiumの実体を指定する場合は `BROWSER_EXECUTABLE` を設定する。

## 30日ランの構成

| 期間 | 期 | 内容 |
| --- | --- | --- |
| 1〜10日目 | 第1期 観察 | T-101 / T-204 / T-309 を巡回し、前兆・速度・呼称・位相の基本を学ぶ |
| 11〜20日目 | 第2期 接触 | 同じ試験室の再割当が増え、過去の自分の記録と照合する。16日目は指定評価業務 |
| 21〜30日目 | 第3期 月末 | 29日目の夜に監督用名札の支給機会、30日目に最終評価と終了分岐 |

- 施設内の異常ルール（許容速度・名札の処遇・給水器の遅延・白い扉の時間倍率）は、サイクル開始時に固定される。日ごとには再抽選しない。
- 死亡すると施設日付だけが1日進み、次のDクラス被験者が同じ施設・同じ封筒を引き継ぐ。個人のC/S/E、名札効果、予約イベントは初期化・取消される。
- 給水器は2日目・12日目・22日目の朝に再設置される。各設置回の飲用は別イベントとして扱い、2〜3日後の夜に複製が現れ、翌朝に比較面接が行われる。
- 有用認定は、16日目と30日目の指定評価業務を同一人物で完了し、最終業務を生還したうえで E=2 / C>=2 / S<=1 を満たすことが条件。途中で死亡して被験者が交代すると、その人物のEは引き継がれない。
- 29日目の夜の安全な再評価業務で C>=2 かつ S<=1 を満たすと監督用名札（SUP-30）が支給され、30日目の朝に脱走未遂の分岐を選べる。
- 30日目の終了判定は「脱走未遂 > 最終日の死亡（欠員補充停止） > 有用認定 > 標準処分」の優先順で1件だけ記録する。

## 操作

| 入力 | 動作 |
| --- | --- |
| W A S D / 矢印 | 移動 |
| Shift（保持） | 走行 |
| Alt（保持）/ C（切替） | 低速歩行 |
| E / F | 調べる・回収する（画面のボタンでも可） |
| マウス | 視線の向き（速度は変わらない） |
| 1〜4 | インターホンへの返答 |
| N | 携帯ノート（実験時計を止める） |
| P / Esc | 設定・ポーズ |

実験中は2秒ごとに自動保存し、再読み込みすると一時停止状態で復元する。「実験を再開」で続きから再開できる。旧7日間サイクルの保存データは、日付・被験者・封筒・事後報告履歴を保持したまま30日スケジュールへ移行する。

## 実装構成

[MVP仕様案](docs/design/NEED_TO_KNOW_MVP仕様案.md)および[設計レビュー](docs/design/NEED_TO_KNOW_レビュー.md)の指摘（R01〜R13）と機能受入条件（AC01〜AC15）を土台に、30日ラン用の日程・再設置給水器・最終日判定を追加しています。エンジン非依存の純粋シミュレーション層と2D視界コーン＋Web Audio＋臨床端末UI層を分離しています。

| ファイル | 役割 |
| --- | --- |
| `src/core/types.ts` | 第9節の分離レコード（`FacilityCycle`, `Subject`, `Trial`, `DeferredEvent`, `ReportArchive`）および型定義 |
| `src/core/rng.ts` | ルール抽選用Seed乱数と演出用乱数の分離、初回固定Seed（`FIXED-DEFAULT`）定義 |
| `src/core/content.ts` | 30日間の固定割当表、3期区分、給水器設置日、4名の同房者脚本、観測・伝聞定義、担当官A/B、事後聴取選択肢、終了分岐4種 |
| `src/core/trials.ts` | `T-101`（歩調）、`T-204`（名札）、`T-309`（白い扉）の状態機械・空間判定・同時判定優先順 |
| `src/core/engine.ts` | 30日間ループ、死亡交代と封筒継承、記憶処理（`S=3 → S=1`）、`W-00`（給水器）遅効比較面接、29日目の監督用名札、終了判定優先表 |
| `src/core/storage.ts` | セーブ／ロード、実験中断時のポーズ復元（AC03）、破損データ保護と自動上書き防止（AC15）、旧7日間保存の30日スケジュール移行 |
| `src/audio/soundEngine.ts` | Web Audio API による手続き型音響生成（半拍遅れの追従足音、急接近前兆、金属脈動音、インターホン音）と前兆優先ダッキング |
| `src/render/canvasRenderer.ts` | 見下ろし2D＋視界コーン（扇形視野）、視界外の音紋（音響フィードバック）、監視カメラ稼働表示、青色非常灯固定点の描画 |
| `src/ui/app.ts` | 収容区画端末UI、30日進捗・3期表示、携帯推理ノート、寝台下の封筒、プレイヤー向け事後報告履歴、実験中保存と再開 |
| `tests/mvp-acceptance.test.ts` | 受入条件 AC01〜AC15 と保存障害の自動テスト |
| `tests/thirty-day-run.test.ts` | 30日スケジュール、30日通し遷移、29日目死亡、最終日死亡、監督用名札、再設置給水器、旧保存移行、新サイクル開始のテスト |
| `tools/browser-smoke.mjs` | 任意のPlaywrightによるブラウザ検証（30日表示・最終日脱走分岐を含む） |
| `tools/thirty-day-ui-smoke.mjs` | 任意のPlaywrightで30日間をUI操作で通し、有用認定エンディングまで確認する検証 |

## 検証

確認日: 2026-10-26。

| コマンド | 結果 | 範囲 |
| --- | --- | --- |
| `npm test` | PASS 25件 | AC01〜AC15の15件＋保存障害3件＋30日ラン7件。判定関数の確認であり、人が30日間を遊べることの実証ではない |
| `npm run build` | PASS | `tsc --noEmit` と Vite本番ビルド |
| `npm run test:browser` | PASS 13項目 | タイトル→朝→T-101開始、30日表示、移動、実験中保存、再読み込み復元、再開、前兆→停止解除、破損保存保護、390px幅、200%文字、30日目脱走分岐、コンソール例外・外部要求0件 |
| `npm run test:30day` | PASS 4項目 | 1日目から30日目までを画面操作で通し、最終T-101を生還して有用認定（E=2, C=3, S=0）へ到達。ページ例外0件 |

### 未検証

- 人が自分の判断で30日間を連続プレイすること（自動UI操作は通したが、推理・操作の面白さは未評価）
- 30日分の通し所要時間・難易度・反復の飽き
- 人によるプレイテスト、面白さ・音の聞こえ方
- Safari / Firefox、モバイル実機、タッチ操作
- 各ACの境界網羅（ACごとに代表1ケースが中心）

## 実装範囲と未実装

30日間を遊べる状態にしたもので、本編仕様の全要素を実装したものではありません。

- 実装済み: 30日スケジュール、3期区分、既存4異常（歩調・名札・給水器・白い扉）の反復、死亡交代、封筒継承、記憶処理、給水器の再設置、16日目/30日目の役割評価、29日目の監督用名札、30日目の4終了分岐、旧保存移行。
- 未実装: 20種以上の異常、10以上の試験室、手続き生成、収容違反イベント、体力・精神・汚染の独立資源、NPCの自律生活・経済、早期処分、幻覚・偽の観測カード、各エンディングの固有エピローグ。
- 30日間は既存4異常の反復で構成している。日ごとの割当内容・担当官は変わるが、異常ルール自体は増えない。
