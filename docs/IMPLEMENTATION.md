## 3. 仕様の解釈と判断

仕様案に明記がなく、実装で決めた点を残す。いずれも再検討対象である。

1. **エンジン**: ブラウザの Canvas 2D と素の ES modules。依存なしでローカル実行でき、判定を Node で試験できることを優先した。エンジン未決の仕様案に対する採択ではない。
2. **通路の幅**: 24距離単位の長さは仕様どおり、幅は3.6距離単位とした。数値は見た目と操作確認のための仮置き。
3. **危険時計**: 接近状態に入った後は、解除入力（停止または低速）の継続中以外は時計が進む。許容速度以下へ戻しただけでは止まらない。「通常歩行に戻すだけでは解除しない」という記述を、時計が止まらない側に解釈した。
4. **解除の継続**: 停止0.5秒と低速1秒は別の継続として数える。停止0.3秒＋低速0.8秒のように混ぜた場合はリセットされる。
5. **出口**: 回収後、接近状態が残っている間は出口に入っても生還しない。解除後に出口へ触れると生還。走行区間の判定は出口判定より先に行う。
6. **インターホン**: 返答中は実験時計を止める。返答は操作を自動化せず、「逆らう」を選んでも走ることはできる。信用は返答ではなく実際の行動と拒否の記録で決める。
7. **走行区間**: 赤線付近を走って通過してから青線まで走り続けた場合に達成。途中で止まると未達になり、赤線へ戻ればやり直せる。
8. **歩調の反復**: 7日間の割当は、学習とEの条件を確認するため毎日「歩調」にした。名札・給水器・白い扉の割当は未実装。これは仕様案の日程表への未達であり、採用ではない。
9. **記憶処理**: 当日に追加された観測・伝聞を削除し、仮説は空欄化する。封筒とプレイヤー向け報告履歴は残す。
10. **死亡報告**: 実際に観測した接近と最終入力だけを記す。「間隔拡大」は停止解除が記録された場合に限る。
11. **期限超過**: 死亡ではなく業務未達とし、指示の有無にかかわらず信用-1。指示の未達・拒否と重なっても、その実験の収支は-1まで。
12. **通常UI**: 信用・疑念の数値、解除に必要な秒数、許容速度を表示しない。操作説明は原理（前兆が先に来る、ポーズ中は止まる等）に留め、解除条件は実験内で観察させる。
13. **保存**: 施設サイクル・被験者・実験・封筒・報告を1つのJSONに保存する。実験中は4秒ごとと画面離脱時に保存する。読み込めないJSONは元キーに残し、明示の退避操作まで書き込まない。
14. **再読み込み**: 保存済みのフェーズへ直接復帰する。実験中は再開確認のポーズを出す。タイトルへ戻る操作は保存する。

## 4. 数値と未検証項目

- 走行4・通常2・低速1距離単位/秒、危険時計3秒、期限120秒、通路24単位、走行区間8単位は仕様案の仮置きをそのまま使った。実測していない。
- 3秒の猶予で2秒の走行区間を抜け、0.5秒停止で解除できることは、状態機械のテストで確認した。人が操作して可能かは未検証。
- 音は WebAudio の合成音のみ。音量0でも字幕が出ることは確認したが、実際の聞こえ方、難聴・騒音環境、ヘッドホン差は未検証。
- モバイル、タッチ操作、ゲームパッド、キー割当変更は未対応。
- 画面のアクセシビリティ監査、色覚差の確認、キーボードのみでの全操作確認は未実施。
- 人によるプレイテスト（仕様案10.2）は NOT_RUN。死亡率・理解度・予備知識差は UNKNOWN_NOT_MEASURED。

## 5. 既知の制限

- 実験の途中で再読み込みすると、再開確認のポーズが出る。保存タイミングによっては直前4秒の入力が失われうる。
- 同房者の会話は5種類で尽きる。7日間の全枠を会話で埋めると、以降は「新しい話はない」となる。
- 封筒は1晩に1回だけ封入できる。同じ夜に複数回の複写はできない。
- 給水器の遅効イベントが無いため、DeferredEvent の保存・取消は未実装。
- 名札と脱走は、6日目の監督用名札と7日目の分岐だけを実装した。名札の誤認・機械認証・再照合は未実装。
- 効果音に外部素材を使っていないため、帰属表示の追加は不要。将来素材を入れる場合は ATTRIBUTION へ追記する。
