# NEED TO KNOW 設計レビュー

2026-10-25 · 対象: [原設計書](NEED_TO_KNOW_ゲーム設計書.md)

## 判断

企画の核は「生存には理解が要るが、理解を示すと研究対象としての価値を失う」という板挟みにある。「指示を信用できない」だけで終わらず、理解した後の振る舞いまで遊びにできる点を残したい。

ただし、現状は体験の企画書であり、実装時の判定を決める仕様が足りない。とくに、死亡とランの関係、前兆から回避までの条件、疑念の根拠を先に固定する必要がある。面白さ、難易度、プレイ時間は未検証である。

このレビューと[具体化仕様案](NEED_TO_KNOW_MVP仕様案.md)は提案であり、原設計の変更や利用者の採択を意味しない。原設計書は変更していない。以下の「原文行」は同梱した原設計書の行番号を指す。

## 提案する変更と、その代償

| 提案 | 得られること | 失うこと・残る課題 |
| --- | --- | --- |
| 施設サイクル中の異常ルールを固定する | 死後も痕跡と実験結果を照合できる | 死亡直後の新鮮さは減る。新サイクルでのみ変化させる |
| 生還でも事後報告書の断片を出す | 生存と情報獲得が同じ方向を向く | 死亡時だけの特別感は文体と失った資産で作る |
| 前兆への反応では疑念を上げない | 学習を使って生き残れる | 「演技」は聴取・根拠の説明・無許可行動に寄せる |
| MVPでは幻覚による偽カードを入れない | 反証可能な推理を先に評価できる | 知覚を疑う恐怖は後段の検証になる |
| 白い扉の手続き生成を後回しにする | 固定ルールと帰還手順を検証できる | 探索の物量とリプレイ性はMVPの受入対象にしない |
| 早期処分を初期MVPから外す | 疑念の因果と回復を観察しやすい | 原案の厳しさは、他の核が成立してから戻す |

## ライセンス記述の確認

2026-10-25にSCP WikiとCreative Commonsの一次資料を閲覧した。以下は公開方針を決めるための確認事項であり、本作全体の権利処理が完了したとの判断ではない。

- SCP Wikiのガイドは派生作品への帰属表示とCC BY-SAの適用を求め、ゲーム向けには個別判断の必要性も記している。原案の「SCPを使えば帰属と継承の検討が必要」という方向は維持する。[SCP Licensing Guide](https://scp-wiki.wikidot.com/licensing-guide)
- 「別のライセンスには変えられない」は広すぎる。CCの互換一覧はBY-SA 3.0の翻案への寄与について、同版・後続版などの条件を示す。GPLv3との一方向互換は4.0について記載され、3.0では非CC互換ライセンスの指定がない。Wikiのゲーム向けGPLv3案内だけで、3.0から直接切り替え可能とは確定しない。[CC Compatible Licenses](https://creativecommons.org/compatible-licenses/)
- CCはソフトウェアそのものへのCCライセンス利用を推奨せず、ゲームの文章・画像・音楽とコードを区別して説明している。したがって「SCPを使うのでコード全体が自動的に公開義務を負う」とも「コードを分ければ必ず適用外」とも、この設計書では断定しない。[CC FAQ: software](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software)
- 独自組織への改名だけで既存の派生表現の義務が消えるとは判断しない。独自世界にする場合も、既存素材・固有表現・文章の由来を確認する。これは本作の素材構成への適用判断が残るという意味である。[CC BY-SA 3.0 Legal Code: Adaptation](https://creativecommons.org/licenses/by-sa/3.0/legalcode.en)

### 原設計への差替え案

> SCP由来の設定・文章・画像等を用いる場合は、出典・作者・適用ライセンスを素材ごとに記録し、帰属と継承の条件を満たす。配布前に、ゲームの派生表現、独立したコード、第三者素材の扱いを整理する。BY-SAの版やGPLv3との互換性には条件があるため、ゲーム全体のライセンスとソース公開範囲は未決とする。独自組織の世界観を選ぶ場合も、名称変更だけで既存の派生表現の義務がなくなるとは扱わない。

SCPを使うか独自世界にするかは、今回の仕様案では決めない。配布方法・収益化・素材の由来と合わせて利用者が選ぶ。

## 実装に進める順序

1. 紙で「同じ前兆を見て、異なる理由で安全行動を選べるか」を確認する。
2. 歩調だけを実装し、停止・低速移動・指示への返答・事後報告を一巡させる。
3. 疑念と聴取を追加し、正しく避けた人が説明不能な罰を受けないか確認する。
4. 1日ループと死亡継承を通す。保存後も同じ異常・同じ日付・同じメモになるか確認する。
5. 名札、給水器、固定構造の白い扉を追加し、7日間の分岐へ接続する。

原案の4異常はそれぞれ速度、社会的認識、遅効性、空間・時間を扱う。4つを同時に試作する前に、歩調で「観察して生き延びることが面白い」を確認する。
