# NEED TO KNOW MVP具体化仕様案

版: draft 0.1 · 2026-10-25 · 採否未確定

> 注: 本文書は7日MVP時点の仕様案である。2026-10-26に30日ランへ拡張した実装を追加したが、本仕様案の採択、人によるプレイテストの完了、30日・20異常への拡張完了を意味しない。30日化の実装範囲は[30日化メモ](../implementation/30日化メモ.md)を参照。

原設計をもとに、実装時に必要な判定と受入条件を補った提案である。原設計の置換や、未決事項の利用者承認を意味しない。[設計レビュー](NEED_TO_KNOW_レビュー.md)の指摘IDと対応させる。

**数値の扱い**: 距離、秒数、閾値、所要時間はすべて試作用の初期値・目標である。実測値や推奨値として検証済みの数値ではない。ゲーム実装・プレイテストは未実施。

## 1. 検証する体験と範囲

検証するのは「危険な指示に対して、観察に基づいて生存行動を選び、その理由を研究員にどう説明するか」である。

**縦切りの完成範囲**は歩調1室、研究員1人、1回の実験、聴取、ノート、事後報告、死亡後の被験者交代までとする。朝と夜は簡単なメニューでよい。目標体験時間は初見10〜15分以内と置き、実測後に見直す。

**7日MVP**はその縦切りを接続する次段階である。歩調・名札・給水器・白い扉の4種、研究員2人、同房者4人、終了分岐3種を扱う。給水器は共用室にあり、専用試験室を要求しない。「試験室4つ」は「専用試験室3つ＋共用室1つ」に変更する提案とする。

| 対象 | 7日MVPの扱い |
| --- | --- |
| 見下ろし2D・視界・音 | 採用案。視界外にも音は届く。遮蔽物を透視しない |
| 変動パラメータ | 施設サイクルごとに固定。各異常で1つだけ変える |
| 白い扉の手続き生成 | 延期。検証済みの固定レイアウトを使う |
| 幻覚・偽の観測カード | 延期。装飾的な不安表現のみ |
| 体力による移動速度低下 | 延期。歩調の閾値と操作検証を混ぜない |
| 記憶処理 | 携帯ノートの写しの一部を消去。ランダム書換えは延期 |
| NPCの自律生活・経済 | 延期。会話と交換は脚本イベント |
| 早期処分・収容違反・異常化 | 延期。7日MVPの通常進行を途切れさせない |
| ソフト・配布 | ローカル・単独プレイを想定。OS、エンジン、ストアは未決 |

## 2. ラン・死亡・継承の定義（R01・R08）

### 2.1 時間と人物を分ける

- **施設サイクル**: 施設内の7暦日。原案の「1ラン」に相当する。この期間中の異常ルールは固定。
- **被験者**: 現在操作する1人のDクラス。死亡・除籍までが1人の在籍期間。
- **新サイクル**: エンド後に明示的に開始する新しい試行。日付を1日目に戻し、新seedで変動パラメータを決める。
- **再開**: 保存済みの同じ施設サイクルを復元する。日付・人物・異常ルールを再抽選しない。

MVPでは「7日後に区画の定期評価と除籍処理がある」と初日の配布文書に記す。30日制そのものを既成事実として7日に置き換えない。本編での30日化と7日MVPの物語上の接続は別途決める。

### 2.2 遷移

```text
新サイクル → 1日目の朝
朝 → 召集 → 実験 → 生還事後 → 夜
夜 → 翌朝（1〜6日目） / 最終評価（7日目）

実験・遅効イベントで死亡 → 死亡報告
死亡報告 → 翌日の朝・新被験者（1〜6日目）
死亡報告 → 終了「処分・欠員補充停止」（7日目）

脱走未遂の確定 → 終了「脱走未遂」
最終評価 → 終了「有用認定」 / 終了「処分」
終了 → タイトル / 明示的に新サイクル開始
```

死亡した日は再実験しない。死亡報告から日付を1つだけ進め、同日の生還事後と夜を飛ばす。時計を戻してやり直す操作は通常プレイには設けない。学習用の固定seed再試行はタイトルからの別モードとし、通常サイクルの進行に混ぜない。

### 2.3 保持範囲

| 情報・状態 | 同じ人物の翌日 | 死亡後の新被験者 | 新サイクル |
| --- | --- | --- | --- |
| 施設日付 | +1 | +1 | 1に戻す |
| seed・異常の変動パラメータ | 保持 | 保持 | 新規抽選 |
| 信用・疑念・役割評価 | 保持 | 初期化 | 初期化 |
| 名札効果・給水器の予約イベント | 保持 | 死亡人物分を取消 | 初期化 |
| 所持品・携帯ノート | 保持。ただし処置対象 | 回収され失う | 初期化 |
| 寝台下に封入したメモ | 保持 | 同じ寝台の次人物が発見できる | 初期化 |
| 観測カード | 携帯写しを保持 | 新人物へ直接移さない | 初期化 |
| プレイヤー向け事後報告履歴 | 保持 | プレイヤーだけ閲覧可 | タイトルの履歴として保持 |

事後報告履歴はプレイヤー向けの画面と明示する。新被験者がその文書を持っている扱いにはしない。過去サイクルの報告には旧施設コード・旧日付を表示し、現在のルールの証明として提示しない。

## 3. 観察と公正さの契約（R02・R04・R05・R12）

### 3.1 事実と仮説

観測できた出来事は同じ条件で再現する。因果・意味・一般化はプレイヤーに委ねる。たとえば「走行開始の後、足音の間隔が短くなった」は事実、「速度が原因だ」は仮説である。

事後報告書も出来事と処置結果を保証するだけで、因果を全文解説しない。「走行開始後、被験者の反応消失を確認」と記録し、「走ると死ぬ」という正解カードは配らない。同じ場面を生還した場合も、観測済みの事実を1件記した断片を出す。死亡回数で情報の解禁量を増やさない。

### 3.2 致死イベントの必須条件

各イベントは次をすべて持つ。

1. 発火条件と、そこへ至るまでの観測機会。
2. 致死処理より先に提示する前兆。画面内か、音・字幕として届くこと。
3. 前兆提示後に入力できる猶予。初期値は通常速度で最低2秒とする。
4. 致死を中断できる行動。移動不能・入力ロック中には要求しない。
5. 中断のフィードバック。音が遠のく等、解釈はできても正解表示にはしない。
6. 危険を解除した後の再発条件。即座に再警告を連打しない。

音・字幕・前兆用の画面表示は同じイベントから出す。字幕は「右後方から足音が重なる」のような知覚情報に留め、「停止せよ」「危険度上昇」とは表示しない。字幕ON/OFFで猶予を変えない。指示の声が前兆音を消さないように優先度を定義する。

遅効イベントでは原因行為の前に不審な観測を置き、結果が致死になる前にも別の前兆と回復機会を置く。消費直後には理解できなくても、不可逆な結末へ無警告で進めない。

### 3.3 ポーズと同時判定

ポーズ、ノート、設定、フォーカス喪失中は実験時計・指示期限・危険進行を止める。死亡・効果確定の後に開いた画面では巻き戻さない。

同じ更新で条件が重なった場合は「既に提示された警告に対する解除入力 → 危険状態更新 → 致死判定 → 退出判定」の順とする。期限ちょうどの解除入力は受理する。未解除の危険を持ったまま出口へ触れても生還扱いにはしない。

## 4. ノート・記憶処理・物証（R04・R09）

### 4.1 データと画面

ノートは観測、伝聞、仮説の3ページを持つ。ページ名は由来を示し、真偽の評価ではない。

| 種別 | 必須項目 | 編集・判定 |
| --- | --- | --- |
| 観測カード | 出来事、施設日付、部屋コード、観測者 | 内容不変。携帯写しは紛失・消去しうる |
| 伝聞カード | 発言内容、話者、入手日、話者の観察日（分かる範囲） | 正誤表示なし。古い情報か比較できる |
| 仮説 | 任意の呼び名、トリガー・効果・条件、根拠カード、自由文 | プレイヤーが自由に変更。空欄も許可 |

枠のラベルは初めから示すが、未観測の正解候補を選択肢として並べない。ゲームは仮説の文字列、単語、正しさを読んで疑念・割当・エンドを決めない。カードを並べなくても操作上の不利益は付けない。ノートの必要性自体はプレイテストで評価する。

### 4.2 隠す・消える

夜に、携帯ノートから観測・伝聞・仮説を合計3件まで寝台下の封筒へ複写できる。各項目は1カードまたは自由文1件とする。複写には夜の行動枠1つを使う。封筒は翌朝に調べて初めて読める。同じ人物でも自動復元しない。

MVPでは封筒は清掃でランダム消去しない。携帯ノートは記憶処理で「直近1日の写し」を消すが、観測の原文を書き換えない。封筒を研究員に見せた場合だけ物証として没収される。腕や靴の隠し場所ごとの確率は後段に回す。

画面は消去されたページを「未記入」として示す。消えた内容を灰色文字・ツールチップ・カード一覧に残さない。プレイヤー向け事後報告履歴は消さない。

## 5. 信用・疑念・評価（R03・R10）

### 5.1 内部値と知覚できる反応

信用Cは0〜3、疑念Sは0〜3。初期値はいずれも0。数値そのものは開発用ログだけに出し、通常画面では配給札、警備の同行、聴取文面で伝える。

| 指標 | 増える出来事 | 減る・回復する出来事 | MVPの影響 |
| --- | --- | --- | --- |
| 信用C | 実験の目的達成、明示された安全な追加業務、禁制メモの任意提出。各イベントで1回だけ+1 | 拒否・明示期限までの未達で-1。同じ試験の未達減点は1まで | 交換機会と最終評価。安全な試験を永久に失わせない |
| 疑念S | 無許可区域への立入、所持根拠なしの機密断言、禁止メモの提示。各イベントで1回だけ+1 | 翌日の安全な再評価業務完了で-1 | 聴取・ノート検査・記憶処理 |
| 役割評価E | 4日目と7日目の歩調で目的物を生還搬出。各1回 | 死亡による人物交代で0に戻る | 有用認定の条件 |

同一の業務で信用の加点と役割評価の加点が同時に起きてよい。役割評価は「指定業務を安全に完了した成果」であり、異常ルールの正答数ではない。歩調・白い扉では目的物を生還搬出、名札では面接完了が各試験の信用加点条件となる。全内部値は判定時に範囲内へ丸める。同じ結果に加減点が重なる場合は差分を合計してから1回だけ丸め、処理順で収支が変わらないようにする。

### 5.2 疑念の判定制限

研究員はカメラで見える行動、インターホンへの返答、聴取で示された証拠だけを使う。カメラの位置と稼働ランプを事前に見せる。部屋全体を監視している場合も配線・表示で分かるようにする。

**前兆を見て停止した、正しい道を選んだ、ノートに正解を書いた、というだけでは疑念を加算しない。** 原案の「完璧な反応」はこの仕様案では採用しない。

聴取では以下のように、説明の選び方を遊びにする。

| 返答・証拠 | 処理 |
| --- | --- |
| 「足音が重なったので止まった」＋その人物の観測記録あり | S変化なし |
| 「足が痛くて遅れた」 | 目的物を回収していればC変化なし。未達ならC-1 |
| 「実験の条件は全部知っている」＋現人物に根拠となる観測・入手メモなし | 聴取イベントに限りS+1。具体的な正解は選択肢に出さない |
| 話さない | S変化なし。業務が未達ならC-1 |
| 隠しメモを任意提出 | 内容の正誤によらずC+1、S+1、提示したメモを没収。同一試験で提出の加点は1回まで |

選択肢には現人物が取得していない機密の具体的な正解を自動追加しない。上表の抽象的な断言は知識を誇示する選択として常に選べる。禁制文書の具体的内容を話せるのは現人物が読んだ後に限り、その場合は無許可の文書閲覧を疑念の根拠とする。自由入力を意味解析して罰する機能は入れない。無許可区域への立入は稼働中のカメラ・警備員・認証端末のいずれかが記録した場合だけSを加算し、根拠のない全知視点で加算しない。

任意提出は信用を得る代わりに物証と秘密を渡す選択となる。提出しなくてもゲームは進行する。「演技」が最適な定型返答を毎回選ぶだけになっていないかは、人によるテストで確認する。

S=1では注意聴取、S=2ではノート検査予告、S=3ではその日の生還事後に1回の記憶処理を行う。処理後S=1。死亡で事後を飛ばした場合はその人物への処理を取消す。朝にS=3になった場合は当日の事後へ処置を予約する。夜にS=3になった場合は直ちに処置してから翌朝へ進む。MVPの疑念は早期処分ではなく回復可能な圧力とし、必須の回復業務は6日目にも用意する。

体力・精神・汚染は7日MVPの独立した数値資源から外す。給水器の遅効性は個別イベントとして管理する。体調の描写は操作速度や必須前兆の信頼性を変更しない。

## 6. 操作・指示・区画の社会（R05・R11・R12）

### 6.1 操作案

キーボード＋マウスを初期対象とする。移動、低速歩行、走行、向き変更、調べる、インターホン返答、ノート、ポーズを別入力にする。移動と視線は独立し、向きを変えただけでは移動速度を変えない。キー割当は実装時に変更可能な形で決める。

移動速度の初期値は低速1、通常2、走行4距離単位/秒。操作説明はこの差を教えるが、異常の許容速度は教えない。メニューを開いてもキャラクターが勝手に歩き続けない。低速歩行は保持式と切替式を用意し、切替状態は通常UIに表示する。

### 6.2 指示のデータ

指示ごとに `id / 話者 / 発話条件 / 本文 / 開始時刻 / 期限 / 目的 / 完了条件 / 未達結果 / 質問への応答` を定義する。内部の「正直・実験目的・誤誘導・沈黙」は通常UIに出さない。

「従う」は操作の自動実行ではなく返答であり、達成は実際の行動で判定する。「遅らせる」は猶予を求める返答で、時計を自動延長しない。「逆らう」は拒否を伝えた後も操作を続けられる。「質問する」は指示ごとに1回で、同じ応答を繰り返して信用・時間を稼げない。

明示的な拒否と、期限までの追加指示未達はC-1とする。ただし同じ実験での指示未達による減点は合計1まで。目的物の回収でC+1を得た後に危険な指示を拒めば、その試験の信用収支は0になる。拒否を無制限に重ねて危険割当に落ちる連鎖は作らない。安全な追加業務でも信用を回復できるため、危険指示への服従を生存の必須条件にしない。

研究員Aは説明を省くが生存に有用な情報を漏らすことがある。研究員Bは丁寧だが負荷を上げる実験を担当する。両者とも安全な指示と危険な指示を持ち、声だけで正誤が決まらない。最初の歩調はA、再試験はBとする。

### 6.3 朝と夜

朝と夜はそれぞれ2行動枠。召集・就寝を選ぶと残りを放棄できる。朝は会話、交換、配布文書の確認、封筒の確認。夜はノート整理、封筒への複写、同房者との会話、安全な追加業務から選ぶ。ノート画面を開くこと自体は枠を使わず、複写だけが1枠を使う。

4人の同房者は観察を話す人、古い経験を話す人、物資交換をする人、研究員へ協力する人を脚本で用意する。正誤の属性はプレイヤーに表示しない。噂には矛盾を検証できる別の記録・現場の痕跡を最低1つ置く。嘘と真実を会話のたびに再抽選しない。

持込枠は任意品2点。各試験の必須支給品は別枠とし、ロープや箱で任意枠を塞がない。物資は鉛筆、紙片、小型鏡に絞る。タバコを含む経済全体は後段。必須の帰還手段を交換で失わせない。

## 7. 異常ごとの実行仕様

以下のA〜Dは開発用の識別であり、通常画面に出さない。部屋コードを表示し、プレイヤーがノートで呼び名を付ける。「歩調」等の呼び名も初期表示には使わない。

### A. 歩調（R02・R05）

**目的**: 直線通路の奥にある箱を回収して退出する。通路長は24距離単位、実験期限は120秒。最低速度の往復でも48秒なので、停止と観察の余地がある初期値とする。

**施設内で固定するルール**: 許容速度以下では追従音だけが続き、接触しない。許容速度を超えると接近する。振り返り自体には効果を持たせない。原案の振り返り効果の抽選は延期する。

**変動パラメータ**: 許容速度を1.5または2.5からサイクル開始時に抽選。前者は低速だけ、後者は低速と通常歩行が安全。走行はどちらも閾値を超える。初回固定seedは2.5にする。

**状態遷移**

```text
追従 / 速度 <= 許容速度: 足音が半拍遅れる。危険時計は0
追従 → 接近 / 速度 > 許容速度: 強い前兆を提示し危険時計を開始
接近 → 接触死 / 超過状態の危険時計が3秒に到達
接近 → 後退 / 停止を0.5秒継続
接近 → 後退 / 低速移動を1秒継続
後退 → 追従 / 足音が遠のく演出を1秒提示、危険時計を0にする
```

接近中に通常歩行へ戻すだけでは、許容速度2.5でも接近状態は解除しない。停止または明確な低速化で解除する。この二段階性を足音の近さで観察できるようにする。解除入力の継続中は危険時計を止める。継続を途中で破棄すると、元の危険時計から再開する。後退中に再び閾値を超えた場合は、後退を中断して新しい前兆付きの接近へ戻す。

**観測**: 自分の停止で別の足音も止まる。走行開始で追従音の間隔が短くなる。床の擦り跡と破れた回収票を置く。視線と速度の切り分けを同じ通路で安全に試せる。

**指示**: 箱を取得した後に「時間がありません、走ってください」。実験全体の残り時間に関係なく、これは負荷指示である。開始時の期限は改変しない。負荷指示は帰路の赤線から青線までの8距離単位を走ることを達成条件とし、線の間以外では走行を要求しない。3秒の接近猶予に対し2秒で走り抜け、その後停止すれば生還可能な初期値である。信用は箱の回収・退出で+1、走行指示の拒否または未達で-1。前兆を観察して避けることには疑念を付けず、信用との小さな交換を残す。

**未達**: 120秒で扉の遮蔽が閉まり回収班が介入する。これは死亡ではなく業務未達、C-1で事後へ進む。期限10秒前に予告を出す。危険時計が既に満了していれば死亡を優先する。

**生還報告の例**: 「回収物を受領。停止区間で追従音の間隔拡大を記録。」死亡報告は直前の入力と身体反応を記す。どちらも未発生の変種ルールを説明しない。

### B. 名札（R06）

**目的**: 支給された別番号の名札を着けて、隣室の面接を終える。

**固定ルール**: 着用が完了すると、人間は名札の番号として扱う。身体・所有物・設備の認証データは変わらない。外してから次の朝の点呼まで効果が残る。着用中は効果を維持し、外した後の再着用では期限を延ばさない。支給試験では面接後に名札を返却させる。重ね着、別名札による上書き、複数対象の同時存在はMVPでは発生させない。

**変動パラメータ**: 支給番号の人物を「翌朝の危険割当対象」または「配給優遇対象」にする。元の人物は別区画へ移送済みと紙面で示す。持続時間の変動は延期。

**前兆と検証**: 面接官の呼称と配給札が変わる。配給窓口の端末だけは元の番号を読む。人間と機械の差を安全な場面で観察できる。聴取前に、名札を外す・異議を出す・訂正用の再照合を受ける選択がある。

**危険割当からの回復**: 翌朝、手元の処遇票に自分の番号との不一致を見せ、無料の再照合を受ければ訂正される。異議を出すこと自体にS加算なし。危険割当は訂正可能な試験条件であり、そのまま即時処分しない。未訂正の場合は、その日の実験前に同じ再照合をもう一度提示する。

**脱走未遂**: 6日目の安全業務で監督用名札を受け取れる。C>=2かつS<=1で支給。7日目の朝、これを着けて人間の門衛を通過できる。ただし外門の生体認証は開かず、職員に捕らえられて「脱走未遂」で終了する。設備の認証が変わらないことと外門の認証方式は6日目までに観察できる。成功する脱走は本編へ残す。

### C. 給水器（R02・R04）

**目的**: 実験としては告知しない。2日目の朝に共用室へ設置される。飲む機会はこの朝の脚本イベント1回だけ。通常の水は別に確保され、飲まないことで脱水・移動不能にはしない。

**固定ルール**: 飲んだ現人物にだけ複製イベントを予約する。夜に現れた複製と翌朝の面接で比較される。複製の信用相当値は1、現人物のC>=1なら現人物を残す。同値は現人物を優先。体力基準の抽選は延期する。原案の「信用を上げると残れる」を定量化した初期案である。

**変動パラメータ**: 発現まで2日または3日。2日目に飲むと4日目または5日目の夜に現れ、5日目または6日目の朝に比較する。3日は初回固定seedとする。

**飲む前の手がかり**: 設置日が空欄の管理票、番号が二重の点呼票、同房者による「飲んだ翌々日から人数が合わない」という日付付きの伝聞。単なる毒物との誤解は医務記録の異常なし所見で反証できる。飲む行為は配布サンプルへの協力としてC+1を1回だけ与える。生存の必須条件にはしない。

**発現前後の回復機会**: 前夜の点呼予告に「面接では応答と協力記録を優先」と記す。複製が現れた朝は通常の召集より前に、短い面接を行う。自分の番号を答える安全な協力課題でC+1を1回得られるため、C=0でも回復できる。無応答を確定する前に「応答のない方を移送する」と再確認する。比較による死亡はその最終選択後に限る。

**取消**: 対象人物が途中で死亡した場合、複製イベントを取消す。次人物へ効果を移さない。同じ朝に比較と他のイベントが重なった場合、比較を解決してから朝の行動枠へ入る。

**設計上の注意**: ここは生存条件の難解さより、日常が実験である発覚を検証する。十分に学んだ人に対し「飲まない」が優位になることは許容する。再プレイで必ず飲ませる罰やランダム強制消費は入れない。

### D. 白い扉（R02・R07）

**目的**: 内部の記録板を回収して同じ入口へ戻る。ロープと記録器は必須支給。

**固定ルール**: 扉の内側では、一定の時間単位ごとに同じ構造が位相A/Bを切り替える。繋がりが変わるのは照明が落ちる瞬間だけ。初期MVPでは手続き生成を行わず、A/Bそれぞれ固定・往復可能なレイアウトを作る。

**変動パラメータ**: 内部時計/外部時計の倍率rを1または2にする。外部の実験期限は180秒。内部時計は外部時間Δtに対してr×Δt進む。各位相は内部時間24秒の安定区間、6秒の前兆区間、位相切替の順とし、前兆区間は実時間6秒または3秒になる。最初の安全な前室で、手元時計と外部時刻を読み上げるインターホンを比較できる。致死となる時間切れは採用せず、期限で回収失敗・C-1として搬出する。原案の20分はMVPの圧縮に合わせて変更する提案。

**帰還の規則**: 青い非常灯のある固定点は位相が変わっても残る。固定点にいる間は再構成に巻き込まれない。ロープは位相変化後には道順を保証せず、切断面と張力変化を前室で安全に観察できる。単にロープを辿り続けても死亡にはしないが、遠回りになる。

**前兆と回避**: 位相変化の実時間6秒または3秒前から照明が脈打ち、金属音が重なる。通行可能な全位置から最寄りの固定点まで、低速移動で2秒以内に到達できる配置にする。固定点以外では位相変化で圧壊死。変化後に次の移動を判断できるよう、安定位相は実時間24秒または12秒になる。初回は前室の観測窓越しに1回だけ変化を見せてから本区画を開く。前室でのデモと時計比較には実験期限を使わず、本区画を開いた時点で180秒を計り始める。

**初期の部屋構成**: 入口E、中継X、中継Y、記録板Pの4室。位相AはE–X–Y–P、位相BはE–Y–X–Pの順に接続する。各室に固定点を1つ置き、位相切替時の人物位置はその固定点に紐づけて維持する。通路と室内の全歩行領域に2秒以内で退避できる固定点を配置する。往復ルートは各倍率で、観測と退避待ちを含め120秒以内に完了できることを制作条件とし、実際のマップで測ってから採用する。

**実装時の必須検証**: A/Bごとの到達可能性、任意位置から固定点への最短時間、入口と記録板の往復経路を地図上で検査する。手続き生成を足す場合もこの条件を生成物すべてに適用する。

## 8. 7日間の割当とエンディング（R08）

### 8.1 割当表

初回の検証では固定順を使い、ランダム割当で再遭遇を失わせない。死亡しても施設の日程は進み、新人物が残りの日程を受ける。

| 日 | 主な割当 | 学習と分岐の役割 |
| --- | --- | --- |
| 1 | 歩調・研究員A | 前兆、速度、停止、初回聴取。夜にメモ複写を教える |
| 2 | 名札の初回試験。朝に給水器設置 | 人間と機械の違い。遅効イベントの起点 |
| 3 | 白い扉の初回試験 | 時計比較、固定点、位相変化。名札の処遇票を訂正可能 |
| 4 | 歩調の再試験・研究員B | 同じルールを別の指示で検証。役割評価Eの1回目 |
| 5 | 名札の再試験 | 機械認証の限界を再確認。給水器イベントの解決候補日 |
| 6 | 白い扉の再試験＋安全な再評価業務 | 帰還手順の再現。S回復と監督用名札の入手機会 |
| 7 | 朝の進路選択。残留なら歩調の最終業務 | 脱走未遂、またはEの2回目と最終評価 |

安全な再評価業務は夜に1行動枠で完了し、C+1、S-1を各1回与える。6日目だけは、完了後の値がC>=2かつS<=1なら監督用名札を支給する。新被験者でも業務自体は可能だが、加点を繰り返して条件を満たすことはできない。

目標時間の仮置きは1日8〜12分、施設サイクル56〜84分。7日の単純積であり、実測ではない。まず歩調で実時間を測り、この枠に合わなければ日数と割当数を再検討する。

### 8.2 終了判定

評価は以下の順で、該当する最初の1件だけを適用する。

| 優先 | 条件 | 結果 |
| --- | --- | --- |
| 1 | 7日目の朝、監督用名札で外門の検問まで進む | 脱走未遂。以後の実験・評価は行わない |
| 2 | 7日目に現人物が死亡 | 処分・欠員補充停止。生前の認定条件があっても適用しない |
| 3 | 最終業務を生還し、現人物のE=2、C>=2、S<=1 | 有用認定 |
| 4 | その他の7日目終了 | 処分 |

有用認定には同じ人物による4日目と7日目の業務が必要。死んで交代を繰り返すだけでは認定に近づかない。一方、死亡で失敗したサイクルでも、残りの異常を観察する機会は残る。

脱走未遂は成功した脱走として記録しない。有用認定は次月を実装せず、継続配属の通知でMVPを終える。処分時は経験した異常の事務記録を1件だけ出すが、正式番号・起源の開示は世界観方針が決まるまで仮文とする。

## 9. 保存と判定データ

エンジンに依存せず、以下を別レコードにする。

| レコード | 主な内容 |
| --- | --- |
| FacilityCycle | cycleId、seed、版、日付、フェーズ、固定パラメータ、日程、封筒 |
| Subject | subjectId、元の番号、C、S、E、持込品、携帯写し、効果、観測根拠 |
| Trial | 試験id、状態、時計、指示の発話・期限・達成、前兆、危険時計、位相 |
| DeferredEvent | 対象subjectId、起点、解決日・フェーズ、取消条件、処理済みid |
| ReportArchive | 旧施設コード、日付、観測者、事後断片、終了種別 |

状態の変更とイベントの処理済み記録は同じ保存単位に含める。生還、死亡、複製比較、記憶処理、日付更新を再開時に重複実行しない。乱数は描画・音のばらつきとルール抽選で分離し、再開によるルール変更を防ぐ。

通常終了時の再開用保存に加え、重要な判定の直後に保存する。中断時は実験内の状態・警告経過も復元し、フォーカス復帰時はポーズで再開する。読み込めない保存は元データを保持し、空データで上書きしない。原データの保持と復元方法はエンジン選定時に具体化する。

正確な内部数値とルール名は開発用ログに分離する。通常の字幕、ノート、ファイル名、説明テキストに正解を流用しない。ローカルゲームのデータ解析を防ぐ暗号化はMVPの要件にしない。

## 10. 受入条件とプレイテスト

### 10.1 実装時の機能受入

現時点の以下はすべてNOT_RUN。数値を含む項目は初期仕様に対する受入条件であり、人が遊びやすいことの実証ではない。

| ID | 条件 |
| --- | --- |
| AC01 | 同じ施設で死亡しても日付は1つだけ進み、異常パラメータと封筒を保持する |
| AC02 | 新人物のC/S/Eと個人効果は初期化され、旧人物の給水器イベントは解決しない |
| AC03 | 再開ではseed・日付・警告時計が保持され、解決済みイベントが再実行されない |
| AC04 | 歩調の両閾値で、低速の往復が可能。閾値超過から停止または低速継続で致死を解除できる |
| AC05 | 前兆なしの致死、入力ロック中の回避要求、ノート中の危険時計進行がない |
| AC06 | 音字幕ON、音量0、通常音声の各条件で、同じタイミングの知覚情報が得られる |
| AC07 | 前兆への反応、仮説の文章、未提示の選択肢だけではSが変わらない |
| AC08 | 同じ指示への質問・同じ目的物・同じ安全業務を繰り返しても加点は1回だけ |
| AC09 | 記憶処理で携帯写しが消え、封筒とプレイヤー向け報告履歴は保持される |
| AC10 | 名札で人間の呼称は変わり、機械の認証と元のsubjectIdは変わらない |
| AC11 | 給水器の2・3日遅延が所定日に解決し、C=0から安全な面接で生存可能になる |
| AC12 | 白い扉の両位相・両倍率で帰還経路があり、全通行位置から固定点へ制限時間内に到達できる |
| AC13 | 生還と死亡の双方で観測した事実に基づく断片を提示し、死亡数だけでは開示を増やさない |
| AC14 | 最終日に複数条件が重なっても、終了判定表の優先順で1件だけ記録する |
| AC15 | 保存破損時に元ファイルを上書きせず、正常な新規データへの自動置換をしない |

### 10.2 人による検証

初回はSCPに詳しい人・詳しくない人を各3名、合計6名とする提案。これは不具合や理解の詰まりを見つける探索テストの人数であり、両群が公平だと統計的に証明する人数ではない。全員に同じ固定seedを配り、条件を揃える。別seedの再検証はその後に行う。

| 問い | 記録するもの | 次の判断 |
| --- | --- | --- |
| 前兆を捉えられるか | 初回前兆への反応、聞こえた内容、字幕の読了、録画上の猶予 | 見えていない・聞こえていないなら提示を直す |
| 因果を試せるか | 仮説、変更した操作、次の結果の予測と実際 | 「何でもランダム」と説明されるなら反証経路を増やす |
| 指示との衝突が成立するか | 従った/逆らった理由、担当者だけを根拠にしたか | 全員が無条件拒否または声当てだけなら指示配置を見直す |
| 疑念の理由が分かるか | 警備・聴取の変化と、本人が考える原因 | 正しく避けた罰だと受け取られたら原因提示を直す |
| ノートが推理を助けるか | 自発的な記入、後日の参照、使わなかった理由 | 利用の強制はせず、入力負荷と参照性を直す |
| 給水器の結末を理解できるか | 飲んだ日、発現までの仮説、面接の選択理由 | 日付と比較基準が繋がらないなら記録を補う |
| 予備知識差が残るか | 群別の初回死亡、試行回数、推理内容、所要時間 | 差の有無を記述。小人数で「差なし」と断定しない |

目標死亡率や満足度の合格率は、初回観察前には置かない。設計上の必須条件に反する即死や説明不能な罰が出たら修正する。成立が確認できるまで30日・20異常への拡張には進まない。
