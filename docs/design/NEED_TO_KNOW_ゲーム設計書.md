# NEED TO KNOW ゲーム設計書

Oct 25, 2026 · @0924h

## 概要

本作は、SCP財団のDクラス職員として、何を担当させられるのか知らされないまま月末まで生き延びる推理型サバイバルホラーである。プレイヤーは異常の名前も危険度も教えられず、観察と推理だけで自分の生存手順を組み立てる。

- **一行説明**: 説明されない実験に毎日送り込まれ、異常のルールを自力で解き明かして生き残る
- **ジャンル**: 推理型サバイバルホラー（ローグライト要素あり）
- **1ラン**: 30日（月末処分まで）。MVPは7日
- **ターゲット体験**: 不安 → 観察 → 仮説 → 検証 → 理解。その底に「財団にとって自分は消耗品」という虚無感
- **想定プレイヤー**: SCPに詳しい層と知らない層の両方。予備知識の差で有利不利が出ない設計にする（情報開示設計を参照）

| 参考作品 | 借りる要素 | 本作の違い |
| --- | --- | --- |
| SCP – Containment Breach | 財団施設、Dクラスの主人公 | 収容違反からの脱出ではなく、日常の「実験」が主舞台 |
| Outer Wilds | 知識だけが進行度になる構造 | 知識の一部がランごとに古くなり、再検証が必要 |
| Return of the Obra Dinn | 断片から真相を推理する | 推理の正誤をゲームが告げない |
| Papers, Please | 体制に従うか逆らうかの選択 | 従順さが生存に効く一方、指示に従うほど死に近づく |
| Lethal Company | 中身の分からない施設へ送り込まれる | 送り込む側の意図が見えず、声だけが届く |

## デザインの柱

すべての設計判断は「Dクラスは知る必要がない（need to know の外側にいる）」という一点から逆算する。

1. **無知が初期状態** — ゲームは異常の正体・番号・オブジェクトクラスを一切示さない。UIもキャラクターが知覚できる情報しか出さない。
2. **指示は味方ではない** — 研究員の指示は実験のためにあり、被験者の生存のためではない。従うか逆らうかを常に問う。
3. **知っていることを悟られるな** — 異常を理解したDクラスは実験データを汚す。知りすぎた素振りは記憶処理や早期処分を招く。
4. **公正な理不尽** — 初見で死ぬことはあっても、死の前には必ず観測可能な前兆がある。死は次の推理の材料になる。

## 情報開示設計

プレイヤーが確定情報を得る手段は「死」と「事後報告書」だけに絞り、それ以外の手がかりはすべて信頼性が不確かなものとして扱う。

| 層 | 内容 | 入手手段 | 信頼性 |
| --- | --- | --- | --- |
| L0 常時既知 | 自分の番号、経過日数、所持品、収容区画の地図 | 最初から | 確実 |
| L1 観察 | 異常の外見、前兆、環境の痕跡 | 試験室での観察 | 事実だが解釈は自由。精神が低いと幻覚が混ざる |
| L2 推論 | 異常のルールの仮説 | 推理ノートで自分で組む | ゲームは正誤を示さない |
| L3 伝聞 | 噂、研究員の失言、盗んだ黒塗り文書 | 区画の社会、盗み | 不確か。嘘・誤解・古い情報を含む |
| L4 事後 | 実験記録の一部 | 死亡時・生還時の事後報告書 | 確実だが一部のみ、黒塗りあり |
| L5 原則不可 | 正式番号、オブジェクトクラス、起源 | エンディングでのみ部分開示 | — |

運用ルール:

- 異常の呼び名はプレイヤーが推理ノートで自分で付ける。ゲーム内に公式名は出さない
- 扉の表示やクリップボードの文書は、重要な部分ほど黒塗りにする
- 「何も言われない」こと自体を情報にする（指示の途切れ、研究員の言い淀み）

**メタ知識問題への対策**: SCPに詳しいプレイヤーは、有名な異常を見た瞬間に対処法が分かってしまい、秘匿が成立しない。そこで次の2点を採る。

1. 既存SCPではなく、本作オリジナルの異常を中心にする
2. 異常ごとに「変動パラメータ」を持たせ、ラン開始時にルールの一部を抽選する。「前回の知識は7割正しい」状態を作り、再検証そのものを遊びにする

## ゲームループ

1日は「区画 → 召集 → 実験 → 事後 → 夜」の5段階で回り、30日目の月末処分までにどう生き延びるか、あるいはどう逃れるかがラン全体の目標になる。

&#91;embedded content: 1日のループ · 5段階、死亡と月末の分岐\]

実験で死ぬと事後報告書でルールの一部が明かされ、次のDクラスが同じ施設で続きを担う。30日目の夜を越えるとエンディング分岐に入る。

**1日の流れ**

1. **収容区画（朝）** — 他のDクラスと噂や物資を交換する。試験室に持ち込める物は1〜2点に限られる。
2. **召集** — 番号が呼ばれる。知らされるのは試験室のコードと、せいぜい作業内容の一語だけ。
3. **実験** — メインのプレイ。インターホン越しの指示を受けながら、異常と同じ空間で規定時間を過ごす。
4. **事後** — 負傷の手当て、聴取、場合によっては記憶処理。事後報告書の断片を得ることがある。
5. **夜** — 推理ノートを整理し、メモを隠す。翌日の割当を左右する出来事が起きることもある。

**1ラン（30日）の構造**

- **1〜10日**: 低リスクの観察試験や清掃作業が中心。区画の人間関係と情報網を作る時期
- **11〜20日**: 接触試験・回収任務など致死性の高い割当が増える
- **21〜30日**: 月末処分が迫る。脱走、有用認定、収容違反の利用などエンディングへの分岐が開く
- 期間中に1回、施設規模の収容違反イベントが起こりうる（MVPでは除外）

## 主要システム

中心は「信用を得るには指示に従う必要があり、指示に従うと死ぬことがある」「生き残るには理解が必要だが、理解を見せると疑われる」という2つの板挟みである。

### 指示システム

研究員の指示はインターホンで届き、次の4種類が混在する。プレイヤーにはどれが来ているか分からない。

| 種類 | 例 | 研究員の意図 |
| --- | --- | --- |
| 正直な指示 | 「赤い線より先に出ないでください」 | 実験の安全確保 |
| 実験目的の指示 | 「対象に触れてください」 | データ取得。被験者の生存とは無関係 |
| 誤誘導 | 「問題ありません、続けてください」 | 被験者の反応を見る |
| 沈黙 | 指示が途中で途切れる | 想定外の事態。それ自体が警告 |

- 選択肢は「従う／遅らせる／逆らう／質問する」。質問はたいてい無視され、逆らうと信用が下がる
- 研究員は声で識別できる。冷淡な者、ヒントを漏らす者、被験者を使い捨てる者がいて、担当の声が危険度の手がかりになる

### 観察と手がかり

手がかりは3系統に分ける。

- **前兆**: 足音が半拍ずれる、照明が一瞬暗くなるなど、効果の発動前に必ず出る兆候
- **痕跡**: 前任者の血痕、壁の引っかき傷、途中で切れたロープ、床のメモ。痕跡そのものが誤っていることもある
- **身体の変化**: 耳鳴り、時間感覚のずれ、記憶の欠落。自分自身が観測装置になる

### 推理ノート

集めた手がかりをカードとして「トリガー」「効果」「条件」の枠に並べ、仮説を組む。ゲームは仮説の正誤を判定せず、試験室で行動に移して初めて検証される。

### 記憶処理

実験後、財団は被験者に記憶処理を施すことがある。受けると推理ノートの一部が消えたり書き換わったりする。

- 対策はメモを物理的に隠すこと（寝台の下、靴の中、腕に書く）
- 狙う体験: 翌朝、自分の筆跡なのに書いた覚えのないメモが見つかる

### 疑念

異常を理解した被験者はデータを汚すため、財団は「知りすぎたDクラス」を警戒する。

- カメラの前で前兆に完璧に反応する、指示より先に正解の行動をとる、といった振る舞いで疑念が上がる
- 閾値を超えると、強い記憶処理・割当変更・早期処分が行われる
- 生き残るには「知っているが、知らないふりをする」演技が要る

### 収容区画の社会

同房のDクラスと噂・物資・仕事を交換する。通貨はタバコ、鉛筆の芯、鏡の破片など。

- 噂は正しいとは限らない。嘘をつく者、古い情報を信じている者、財団の協力者が混ざる
- 同房者は実験で死んだり入れ替わったりする。昨日と話が噛み合わない者は要注意

### ステータス

| 項目 | 役割 | 悪化すると |
| --- | --- | --- |
| 体力 | 負傷の蓄積 | 移動が遅くなる。多くの異常は即死なので主軸ではない |
| 精神 | 知覚の信頼性 | 観察に幻覚が混ざり、偽の手がかりが出る |
| 信用 | 研究員からの評価 | 配給減、危険な割当、処分の前倒し |
| 疑念 | 知りすぎの度合い | 強い記憶処理、早期処分 |
| 汚染 | 異常の残留影響 | 遅効性の効果が発動する |

## 異常の設計

異常は「表向きの指示・実際のルール・前兆・誤解しやすい解釈・変動パラメータ」で定義し、致死的な効果の前に観測可能な前兆を最低1つ置く。

**設計ルール**

- ルールは一貫させる。同じ条件なら毎回同じことが起きる（変動パラメータはラン開始時に固定）
- 致死性の発動前に、観測可能な前兆を最低1つ置く
- もっともらしい誤解を、意図して1つ仕込む
- 複雑さは3段階: 単一ルール／ルール2つ／ルール＋例外
- 有名な既存SCPの構造をそのままなぞらない
- オブジェクトクラスの印象と実際の危険度を一致させない。安全そうな物ほど扱い次第で致命的にする

### サンプル1「歩調」（通路試験）

- **表向きの指示**: 「突き当たりの扉まで歩き、箱を回収して戻ってください」
- **実際のルール**: 被験者が移動している間だけ、背後に何かが追従する。走ると急速に接近し、接触すると致死
- **前兆**: 自分の足音に半拍遅れて別の足音が重なる。床に一定間隔の擦り跡がある
- **指示との衝突**: 帰路で「時間がありません、走ってください」と言われる。研究員が見たいのは走行時の挙動
- **誤解しやすい解釈**: 「振り返らなければ安全」。実際の要因は速度
- **変動パラメータ**: 振り返ったときの効果（無効／接近／一時停止）、許容速度

### サンプル2「給水器」（告げられない実験）

- **表向きの指示**: なし。ある日から収容区画の休憩室に置かれている
- **実際のルール**: 飲んだ者の房に、3日後の夜「もう一人」が現れる。翌朝、研究員はより協力的な方を残す
- **前兆**: 同房者と昨日の話が噛み合わない。点呼の人数が一瞬合わない。給水器の管理タグに設置日がない
- **誤解しやすい解釈**: 毒や病気だと思って医務室へ行く。医務室では何も見つからない
- **生存方法**: 飲まない。飲んだなら3日目までに信用を上げておく
- **変動パラメータ**: 発現までの日数、残される側の基準（協力性／体力）
- **狙い**: 実験だと告げられないまま実験されている、という情報秘匿の極端な形

### サンプル3「名札」（社会系）

- **表向きの指示**: 「この名札を着けて、隣室の職員の質問に答えてください」。名札には別のDクラス番号
- **実際のルール**: 着用者は全員から名札の番号の人物として認識される。外しても24時間続く
- **前兆**: 自分の番号で呼ばれない。配給の量が変わる。知らない囚人に親しげに話しかけられる
- **展開**: 名札の番号が翌日処分予定の者なら危機に、職員の名札を手に入れれば脱走ルートになる
- **変動パラメータ**: 持続時間、名札の番号の人物の境遇

### サンプル4「白い扉」（探索系）

- **表向きの指示**: 「扉の向こうを記録し、20分以内に戻ってください」。ロープとカメラを渡される
- **実際のルール**: 扉の向こうは入るたびに構造が変わる空間。内部の時間の流れは外と一致しない
- **前兆**: 扉の脇に前任者のロープが残り、途中で切られている。結び目が自分の結び方と同じ
- **誤解しやすい解釈**: 「ロープを辿れば戻れる」。ロープは途中で別の場所につながる
- **変動パラメータ**: 内部構造（手続き生成）、時間の倍率
- **役割**: 繰り返し遊べる探索パートとして、手続き生成で割当を量産する

## 死と継承

Dクラスが死ぬと、プレイヤーは次のDクラスとして同じ施設に配属され、前任者が隠したメモや残した痕跡はそのまま施設に残る。

- 死亡時には、その実験の事後報告書を見せる。財団の事務的な書式で自分の死が1行で記録され、異常のルールの一部が明かされる（一部は黒塗り）
- 前任者のメモは、次のキャラクターにとって「痕跡」になる。ただし清掃や捜索で消されることがあり、財団に見つかると疑念が上がる
- プレイヤー本人の記憶は当然引き継がれる。だからこそ変動パラメータで「前回の知識をそのまま信じると死ぬ」場面を作る

### エンディング

| エンディング | 条件の例 | 開示される情報 |
| --- | --- | --- |
| 処分 | 30日目を迎える（既定） | 関わった異常の正式な記録が1件だけ明かされる |
| 有用認定 | 特定の異常に耐性や適性を示す | 専属被験者として翌月へ。新しい割当が解放される |
| 脱走 | 名札や収容違反を利用して施設の外へ出る | 財団の外から見た施設の姿 |
| 異常化 | 汚染を受け入れ続ける | 自分自身が収容対象になり、自分についての報告書を読む |

## 表現とUI

MVPは見下ろし型2Dに視界コーン（扇形の視野）を組み合わせる。視線をトリガーにする異常を表現でき、一人称3Dより制作コストが低い。

- **視点**: 見下ろし2D＋視界コーン。視界の外は暗く、音だけが届く。一人称への移行は本編で再検討
- **UI**: 財団文書の書式を模し、重要な部分ほど黒塗りにする。数値ゲージは最小限にし、状態は描写で伝える
- **音**: インターホンのノイズ、漏れ聞こえる研究員同士の会話、前兆の足音。音を最大の情報源にする
- **トーン**: 臨床的で冷たい。財団は悪意ではなく効率で人を使い捨てる。恐怖は驚かしより「分からなさ」で作る
- **文章**: 指示文と事後報告書は短く事務的に。推理ノートだけが人間の声になる

## MVPスコープ

MVPは「7日間・異常4種・試験室4つ」で、情報秘匿の核（指示・推理ノート・事後報告書・疑念）が面白いかを検証する。

| 項目 | MVP | 本編 |
| --- | --- | --- |
| 期間 | 7日 | 30日 |
| 異常 | 4種（サンプル1〜4） | 20種以上＋変動パラメータ |
| 試験室 | 4 | 10以上＋手続き生成 |
| 研究員 | 2人 | 5人 |
| 同房者 | 4人 | 入れ替わりあり |
| エンディング | 処分・有用認定・脱走未遂 | 4種＋分岐 |
| 収容違反 | なし | 1ランに最大1回 |
| 継承 | 次キャラへのメモ引き継ぎのみ | 痕跡システム全体 |

**開発フェーズ**

1. **紙プロトタイプ** — 異常カードと指示カードで、推理と指示の衝突が遊びとして成立するか確かめる
2. **単一試験室の縦切り** — 「歩調」1つで、前兆 → 仮説 → 検証 → 事後報告書の1サイクルを実装する
3. **1日ループ** — 区画・召集・実験・事後・夜をつなぐ
4. **MVP 7日間** — 異常4種、疑念と記憶処理、エンディング3種を入れる
5. **プレイテスト** — SCPに詳しい人と知らない人の両方に遊んでもらい、予備知識による有利不利を測る
